## 2026-03-24 - Optimization of Google Fonts Import & Speedometer Rendering
**Learning:** External `@import` statements inside CSS files block page rendering because the browser has to request, download, and parse the imported stylesheet in series after the host stylesheet is downloaded. Moving the fonts loading into direct HTML `<link>` headers alongside `preconnect` tags dramatically improves First Contentful Paint (FCP) and Largest Contentful Paint (LCP) by parallelizing request pipelines. Furthermore, in high-frequency animation engines powered by `requestAnimationFrame`, updating text-based DOM nodes (like speed and RPM values) on every single frame causes layout thrashing even when the numerical value has not mathematically changed.
**Action:** Always preconnect to third-party CDNs and load fonts or external assets using native `<link>` elements inside HTML headers rather than CSS `@import`. For continuous animation engines, always cache and compare intermediate calculations, applying DOM mutations only when a visible state/integer transition occurs.
