## 2026-03-30 - High-Contrast Focus Visible & ARIA Labels for Touch HMI
**Learning:** Custom dark-themed touchscreen HMI interfaces lack default focus visibility and accessible names for icon-only controls, making keyboard and assistive navigation invisible or unusable.
**Action:** Always provide explicit `:focus-visible` styles using theme accent CSS variables and add `aria-label` to all icon-only buttons and form controls.
