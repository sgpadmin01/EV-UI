## 2026-03-01 - Accessible Custom Form Controls in Agricultural Touch HMIs
**Learning:** Custom UI controls such as toggle switches (implemented via hidden checkboxes overlaid with styled spans) and range sliders lack inherent accessibility because their visual labels are disconnected from their underlying interactive input elements, preventing screen readers from announcing their context. Furthermore, focus styles must target the visible element (the custom slider or thumb wrapper) rather than the hidden native input.
**Action:** Associate labels with custom interactive controls using `aria-labelledby` referencing specific IDs on the label spans. Apply high-contrast `:focus-visible` styles to the visible interactive elements, such as using `.hmi-toggle input:focus-visible + .hmi-toggle-slider` to show clear focus outlines on touchscreens for keyboard/accessible navigation.
