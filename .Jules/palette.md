## 2025-03-03 - Accessible Tabbed Navigation and High-Contrast Focus Visuals in Touchscreen HMIs
**Learning:** Touchscreen interfaces (such as this fixed 1024x600 embedded HMI display) must support assistive technologies and keyboard layout navigability. Applying standard WAI-ARIA tab layout structures (`role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`, `role="tabpanel"`) ensures screen readers can announce dynamic tab panel visibility and state changes. Custom form controllers, such as range sliders and toggles, should also use `aria-labelledby` to associate inputs with descriptive labels. Furthermore, adding `:focus-visible` outline rings ensures high-contrast visual indicators are reserved only for keyboard/hardware focused states, avoiding visual clutter for touch users.
**Action:** Always structure non-framework navigation tabs using semantic ARIA tablist roles, synchronize selected state attributes in client-side state transitions, associate form labels explicitly using matching ID attributes, and include clear focus indicators for alternative navigability.
