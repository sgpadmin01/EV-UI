## 2026-03-05 - Touchscreen HMI Keyboard Focus & Custom Element Accessibility
**Learning:** Programmatic `.focus()` in automated environments does not trigger `:focus-visible` styles; native keyboard interactions (like Tab key presses) must be simulated to verify focus state visual indicators. For custom touchscreen controls like toggle switches where the original `<input type="checkbox">` is hidden (e.g. `opacity: 0`), the focus ring must be mapped to the adjacent visible wrapper using sibling selectors (`input:focus-visible + .hmi-toggle-slider`).
**Action:** Always map focus states to the visible selectors using relative sibling combinators for custom switches, and trigger native Tab keyboard inputs during verification testing to guarantee visual focus outlines display correctly.
