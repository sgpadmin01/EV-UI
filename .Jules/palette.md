## 2025-08-05 - Interactive Touch Dimming & Accessible Inputs
**Learning:** For physical hardware HMIs (like a dark-themed 1024x600 touch panel), implementing realistic visual feedback such as screen brightness dimming can be elegantly achieved on the frontend using hardware-accelerated CSS `filter: brightness(X%)` on the viewport container. This offers immediate tactile simulation without performance lag or canvas re-rendering. Additionally, inputs (like range sliders) on small touchscreen panels require clear label mapping (`for`/`id`) to support text-click accessibility and clear screen-reader feedback (`aria-label`).
**Action:** Always link touchscreen slider inputs to semantic label elements and leverage root CSS transitions and filters for device-like responsiveness on embedded displays.
