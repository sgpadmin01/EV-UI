## 2026-08-09 - High-Frequency DOM Telemetry Optimization
**Learning:** In highly visual and real-time dashboard applications (such as embedded HMIs), continuous simulated data feeds or fast timer loops (like 1000ms clock intervals or sub-second animation frames) can lead to constant DOM `.textContent` writes and style mutations. Even if the calculated value is identical to the previous cycle, setting `.textContent` or updating `.style` triggers costly browser layout reflows and repaints, which severely spikes CPU and power usage.
**Action:** Always implement local state cache guards (dirty checking) on high-frequency UI updates. Compare newly computed visual telemetry states against previously stored values, and only apply DOM writes, class toggles, or CSS property adjustments when an actual state change has occurred.
