## 2026-08-12 - Missing Standard Security Headers and Information Disclosure
**Vulnerability:** The application server served static HMI client assets and api endpoints without standard HTTP security headers (such as Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, etc.), and disclosed internal implementation technology by emitting the default `X-Powered-By: Express` header.
**Learning:** By default, Express 5 does not secure HTTP responses with headers against Clickjacking, MIME-sniffing, or XSS, nor does it constrain where scripts/fonts can be loaded from. Furthermore, exposing backend platform information via `X-Powered-By` helps attackers map the attack surface and fingerprint the exact backend technologies.
**Prevention:** Always explicitly disable the `X-Powered-By` header utilizing `app.disable('x-powered-by')` and configure a comprehensive set of secure HTTP headers (especially a tailored `Content-Security-Policy` restricting script/style sources to trusted CDNs like unpkg.com) via a middleware.
