## 2026-08-09 - Missing Secure Headers and Information Disclosure in Express Backend
**Vulnerability:** The Express backend lacked crucial HTTP response headers such as Content-Security-Policy (CSP), X-Frame-Options, X-Content-Type-Options, Referrer-Policy, and X-XSS-Protection. It also exposed the technology stack via the default `X-Powered-By: Express` header, leaving the HMI touchscreen application susceptible to framing attacks, MIME-sniffing, XSS, and technology-based targeting.
**Learning:** In lightweight, dependency-free Express setups, security headers are often overlooked because standard middleware like Helmet is avoided to keep the codebase simple. Standardizing on custom, dependency-free middleware ensures security without introducing external dependencies.
**Prevention:** Always implement custom security middleware in the main entry point (`server/index.js`) to set a baseline of robust headers and explicitly disable default technology headers like `X-Powered-By`.
